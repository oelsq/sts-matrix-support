# Передача живым сотрудникам

В каждом департаменте пять аккаунтов. Команды пользователя: `!юрдеп`, `!финдеп`, `!человек`. Можно дописать вопрос после команды. Бот передаёт последний вопрос и ответ ИИ по явному запросу. Новая переписка получает одного сотрудника по кругу; назначения и очередь сохраняются в SQLite. Уже начатая переписка остаётся у того же сотрудника.

Бот приглашает только пользователя и назначенного сотрудника. После присоединения человека бот выходит и не отвечает в этой комнате. Пользователи могут переписываться в Element вручную. Учёта рабочего времени, присутствия, автоматического закрытия тикетов и переназначения пока нет.

Логины новой установки: `@jurdep:demo.local` и `@jurdep2`–`@jurdep5:demo.local`; аналогично `@findep` и `@findep2`–`@findep5`. При другом `MATRIX_SERVER_NAME` меняется часть после двоеточия. Локальные пароли — `runtime/accounts.txt`. Используйте разные профили браузера для пользователя и сотрудника.
