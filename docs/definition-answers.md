# Определения ГПХ и ГЭСВ

`matrix_support_bot/term_definitions.py` распознаёт только отдельный вопрос о значении этих двух терминов: например, «ГПХ — это что?» или «Расшифруй ГЭСВ». Расчёты, суммы, сроки, налоги, споры, сравнения и просьбы написать документ не подменяются кратким определением. Упоминание ГПХ в таком вопросе не считается сообщением о заключённом договоре пользователя.

Для быстрого ответа проверяются конкретные исходные фрагменты. ГПХ требует терминологическую выдержку и определение договора из статьи 378. ГЭСВ требует официальную расшифровку и пункт с определением в банковских правилах. Состав платежей добавляется вместе с исключением для нарушения договора; вопрос о депозите не получает правила расходов по займу. Если обязательного фрагмента нет или он изменён, готовый текст не используется: запрос идёт дальше по обычному защищённому пути.

В модельном пути `definition_focus()` указывает, какие источники и Q-локаторы подтверждают каждую часть определения. Для разорванного PDF-предложения передаются обе строки. Для исключения передаются отрицательный заголовок и пункт перечня. Цитаты берутся из текущего запроса; новые источники или разрешения на неподтверждённые утверждения не создаются. Проверяющий код Flowise и Python продолжает проверять настоящие цитаты и числовые факты.

Поиск отдаёт приоритет самому определению. В базе добавлена только короткая терминологическая подпись калькулятора АРРФР (`gesv-term-guide`); она не является новым правилом расчёта или источником ставки. Предыдущие документы, их даты проверки и модельные веса сохранены.

Нормальный бот может выдать проверенное определение без вызова модели. В отчётах этот механизм отмечается `source_bound_definition`. Принудительные модельные проверки используют общий `prepare_model_evidence` и настоящий Agentflow; они считаются отдельно. Разница важна: хороший готовый ответ ещё не доказывает улучшения генерации модели.

В `config/definition-cases-20261101.json` до исправления зафиксированы 16 основных модельных вопросов, 8 дополнительных формулировок и 16 отрицательных границ. Дополнительные формулировки отложены для модельного прогона, но участвовали в локальных проверках распознавания; это не полностью независимый экспертный набор. Отдельные регрессии проверяют смешанные запросы и неизменность доказательств. Результаты — в отчёте `reports/definitions-20261101.md`.
