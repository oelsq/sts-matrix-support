# Свободный режим двух агентов

Основной ответ готовит сама подключённая модель: один вызов LiteLLM вместо обязательного черновика, аудита утверждений, доработки и повторного аудита Flowise. ЮрАгент и ФинАгент остаются отдельными чатами с разными инструкциями. История ограничена вопросами этого пользователя в этой комнате; данные других пользователей не добавляются.

Документы используются как необязательная справка. Поиск ограничен ожиданием 3 секунды, передаётся не более четырёх фрагментов. Отсутствие источника не блокирует объяснение из общих знаний модели. Модель должна обозначать неопределённость конкретных действующих сроков, ставок и условий. Нельзя называть этот режим автоматической юридической экспертизой: обязательной проверки утверждений здесь нет. Веса модели не меняются и PDF не превращаются в обучение весов.

Команды `!помощь`, `!новый`, `!база`, `!сотрудники`, `!человек`, выбор департамента и сотрудника сохраняются. Обычные вопросы о возможностях и приветствия в свободных комнатах обрабатывает модель. Чистую арифметику и явно указанные начисления минус все удержания считает проверенный инструмент. Срочные готовые памятки по защите доступа сохраняются. Ошибка генерации получает честное сообщение и предложение `!человек`; обращение не передаётся без команды пользователя.

## Настройка

`MATRIX_FREE_REPLY_ROOMS_FILE` указывает на JSON-словарь `{"!room:server": "legal", "!other:server": "finance"}`. Каждая комната должна совпасть с явным маршрутом юридического/финансового чата. Другие комнаты сохраняют прежний режим.

При новой установке через стандартный Compose по умолчанию используется `/app/state/room_routes.json`, который создаёт `scripts/setup.py` для двух основных чатов. Явное пустое значение переменной отключает свободный маршрут. При запуске `bot.py` без этой переменной сохраняется старый режим, чтобы существующие установки не переключались неожиданно.

На текущей VM включение задаётся отдельным Compose overlay и защищённым файлом списка двух основных комнат внутри состояния STS. Старые Agentflows сохранены для возврата и продолжают обслуживать комнаты, не включённые в свободный список. Основные свободные комнаты не вызывают их проверяющую цепочку.

После изменения переменной или файла нужен перезапуск только бота. Лимиты Synapse, сервер модели, GPU и другие сервисы эта настройка не меняет.

## Код

- `matrix_support_bot/free_reply.py` — выбор комнаты, необязательный поиск, один запрос к модели, оформление источников и отказ сервиса.
- `matrix_support_bot/agents/free_common.md` — общий стиль и правила свободного ответа.
- `matrix_support_bot/agents/free_legal.md`, `free_finance.md` — специализация.
- `matrix_support_bot/bot.py` — подключение режима до старой ветки локальных ответов/Agentflows.
- `matrix_support_bot/tests/test_free_reply.py` — проверка одного вызова, изоляции маршрутов, отсутствия отказа без PDF, расчётов и реальной обработки события ботом.

Максимум одной генерации — 2200 токенов, температура 0,3; тайм-аут запроса 75 секунд. Обрыв по длине не уничтожает доступную часть ответа. Текст форматируется существующим безопасным Markdown/HTML-рендерером. Модель не получает инструменты запуска команд, перевода денег, чтения чужих чатов или отправки обращений.
