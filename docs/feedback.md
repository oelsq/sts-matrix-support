# Добровольная оценка ответа

В чате ЮрАгента или ФинАгента можно оценить свой последний доставленный ответ:

- `!оценка полезно`
- `!оценка неполно`
- `!оценка ошибка`
- `!оценка не помогло`

Команда не обращается к модели. Оценка относится только к последнему ответу этому пользователю в этой комнате. Ответ другого человека, другая комната, недоставленное сообщение и служебная справка не становятся целью оценки. На один ответ приходится один голос; новая категория заменяет прежнюю, повтор той же категории не увеличивает счётчик. Старые ответы до установки этой функции не получают метку направления задним числом.

В таблицу `answer_feedback` существующей закрытой inbox-базы попадают только непрозрачный маркер ответа, направление, категория и день по UTC. Тексты вопросов/ответов, имена и Matrix-идентификаторы туда не копируются. Маркер нужен для защиты от повторного счёта; это псевдонимизация, а не обещание невозможности связать запись с другими данными администратора VM. Старые записи очищаются при запуске бота и новых оценках, окно — 90 дней.

Администратор может получить только суммы категорий:

```sh
docker exec sts-team-demo-bot-1 python /app/tools/feedback_metrics.py --inbox /app/handoff_state/matrix_inbox.sqlite3
```

В переносимой сборке путь состояния может быть `/app/state/matrix_inbox.sqlite3`. Скрипт открывает SQLite только для чтения и не выводит маркеры ответов, комнаты, пользователей или переписки. При необходимости `--output` сохраняет итог в файл с правами 0600.

`ошибка` сохраняется как `suspected_error`: это сообщение пользователя о возможной ошибке, не установленное нарушение закона. Добровольные оценки имеют смещение выборки и не являются процентом юридически правильных ответов. Они не меняют автоматически инструкции, документы или веса модели. Для существенных замечаний нужен разбор источников; экспертный статус остаётся отдельным.

Команда не добавляется навязчивым текстом к каждому ответу. Её описание есть в `!помощь`. Выбор другого сотрудника через `!другой`, `!юрдеп2` и `!финдеп3` работает отдельно.
