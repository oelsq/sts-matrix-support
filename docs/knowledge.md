# PDF-база ЮрАгента и ФинАгента

Снимок проверен на 01.10.2026: 2 закона «Әділет» (полный текст, экспорт в локальный PDF) и 4 исходных PDF тарифов Halyk/Freedom. Каталог: offline_knowledge/manifest.json, контроль каждой версии SHA-256. Полный список и происхождение: offline_knowledge/README.md.

Обычный docker-compose.yml подключает каталог только для чтения. KNOWLEDGE_DIR активирует PDF-поиск как с существующим шлюзом, так и с локальной моделью. OFFLINE_MODE=1 дополнительно проверяет разрешённые локальные адреса Matrix/LLM; используйте отдельную offline-конфигурацию.

Сценарий: вопрос в Element -> маршрут комнаты legal/finance -> поиск по локальным PDF -> найденные фрагменты с номерами страниц передаются LLM -> ответ с ID цитат -> сервер проверяет, что ID существуют в переданных фрагментах. Это контроль ссылок, а не автоматическая экспертиза юридической правильности всего текста. Поиск сохраняет строки/колонки PDF и заголовки статей. При вопросе о тарифах без банка требуется уточнение.

Для пересборки только бота: docker compose build bot; docker compose up -d --no-deps bot. В логах должна быть строка Local PDF knowledge loaded. Проверьте вопросы о претензии потребителя, коммунальных платежах Halyk и открытии счёта Freedom. Ответ должен указывать документ и страницу, а не только ссылку на сайт.

Каталог PDF намеренно исключён из Git. Передайте Amirzhan исходники проекта и offline_knowledge целиком, без .env.bot, токенов и паролей. Для развёртывания полностью без интернета заранее подготовьте Docker-образы и локальную модель; в текущем демо LLM-шлюз внешний.

Для обновления: сверить официальный текущий каталог/редакцию и дату вступления, заменить PDF, обновить sha256/reviewed_on/version в manifest.json, проверить извлечение/поиск и перезапустить bot. Не использовать автоматически архивные PDF. PDF без текста требует проверенного OCR до импорта.
