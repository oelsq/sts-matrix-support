Документы хранятся локально; поиск не обращается к интернету. Генерация ответов в текущем демо использует ранее настроенный LLM-шлюз. Для полностью изолированной сети используйте docker-compose.offline.yml и локальную модель.

Обновление: скачать новую редакцию, сверить статус и даты, заменить файл, обновить sha256 и reviewed_on в manifest.json, проверить поиск и перезапустить только bot. Никогда не отмечать файл проверенным без сверки первоисточника.
