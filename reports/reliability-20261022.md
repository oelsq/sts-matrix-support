# Надёжность ответов и восстановление запросов — 22–23 октября 2026

Изменения установлены в `~/sts-matrix-support/project` на VM. Два действующих защищённых Agentflows V2 обновлены без изменения их ID и четырёх маршрутов комнат. Подробные записи синтетических проверок хранятся только на VM с правами 0600; JSON рядом с этим отчётом содержит сводные показатели без переписки и токенов.

## Что исправлено

- Проверка распознаваемых числовых утверждений связывает показатель, число, единицу и ограничение. Пример регрессии: «Комиссия 0 тенге. Лимит 100 тенге» больше не подтверждает «Комиссия 100 тенге», даже если модель ошибочно одобрила всю цитату. Проверены валюта, рабочие/календарные дни, точное значение и «не более».
- До Element передаются именно выдержки, выбранные проверкой утверждений. Повторный выбор цитаты по словам вопроса исключён для проверенных ответов. Отметка `partial` видна пользователю, включая проверенный запрос данных для расчёта без фактических утверждений.
- Вопросы, cursor синхронизации, готовые ответы и идентификаторы отправки сохраняются в приватном SQLite. После обычного перезапуска восстанавливается Matrix-сессия; повтор отправки использует тот же текст и transaction ID. Контекст незавершённого запроса не изменяется из-за повторной обработки.
- Ограниченная Matrix timeline догружается до сохранённого события. Ошибка восстановления оставляет cursor прежним. Комнаты сотрудников исключены до запроса истории. Старые сообщения до первого включения хранилища не проигрываются заново.
- Общий вопрос о включении комиссий и страховки в ГЭСВ больше не блокируется как тариф неизвестного банка. Найдены восемь подходящих фрагментов; сформирован ответ по правилам расчёта и перечню платежей.
- Правовое утверждение внутри фразы «Уточните, что договор не может…» больше не считается автоматически безопасным советом. Короткое «Что регулирует…» получает формат определения.
- Ручная проверка нашла смысловую ошибку о брачном договоре: нельзя смешивать допускаемые условия об имущественном положении детей с ограничениями на регулирование прав и обязанностей супругов в отношении детей. Добавлен ответ, требующий наличия всех соответствующих норм в найденных фрагментах и сохраняющий точные цитаты. При отсутствии нужной нормы он не применяется.

## Практические пределы

Числовой фильтр распознаёт ограниченный набор русских обозначений показателей и единиц; ячейки таблиц без заголовков, субъект и условия нормы по-прежнему требуют смысловой проверки. Ручной тест выявил ошибку, пропущенную моделью: положительный аудит не равен заключению юриста. Модель, база и проверка не гарантируют правильный ответ на любой вопрос.

Восстановление проверено после первого сохранённого cursor и при обычном перезапуске с сохранённой Matrix-сессией. Отзыв токена, потеря базы состояния или изменение серверных правил дедупликации требуют отдельного восстановления; абсолютное exactly-once для всех отказов не заявляется. Проверка при остановке не является нагрузочным тестом на сотни одновременных пользователей.
