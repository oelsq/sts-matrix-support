## Что улучшено в ответах

Новый ограниченный обработчик возвращает конкретные шаги и настоящий черновик заявления об ошибке в кредитной истории; объясняет получение собственного отчёта, давление из-за профсоюза, проверку документов для долевого участия и удержание расходов страховщика после ДТП. Он срабатывает только при наличии определяющих фрагментов. Отсутствие/изменение ключевой нормы отключает готовое разъяснение.

Предупреждение Нацбанка о подозрительном уведомлении о статусе займа идёт раньше общей процедуры исправления истории. Ответ предлагает проверить историю через официальный источник, не переходить по присланной ссылке и не вводить данные в подозрительную форму. Цитаты о самом уведомлении и официальном способе проверки привязаны к своим фрагментам.

Вручную выборочно сопоставлены семь новых типов объяснений с определяющими положениями. Сохранены важные границы: ошибка не равна достоверной просрочке; страховые расходы самого страховщика не равны любому частному счёту за оценку; способы долевого строительства — альтернативы. Не обещаются выдача кредита, безусловное удаление записи, автоматический возврат денег или компенсация.

Заявление содержит редактируемые поля и сам текст обращения. Запрос судебного иска, расчёта или срока не подменяется этим шаблоном. Для аренды квартиры в новостройке не выдаётся памятка для дольщика. Материалы источника больше не дублируются, когда одна и та же выдержка подтверждает несколько частей ответа. Формируется обычный rich-text Matrix: абзацы, списки, переносы полей и компактные карточки источников; реальный интерфейс Element без VM не просматривался.

Расширение сначала вызвало ошибки ранжирования. Они исправлены до итогового прогона: 76/96 новых вопросов стали 96/96; восстановлены статья об условиях бесплатной юридической помощи и приоритет предупреждения о фишинге в прежнем контрольном наборе.

## Воспроизведение

```bash
DATABASE_URL=sqlite:////tmp/sts-knowledge-tests.sqlite3 python -m pytest -q
python scripts/evaluate_answers.py --output /tmp/core-retrieval.json
python scripts/evaluate_answers.py --cases config/expanded-knowledge-evaluation.json --output /tmp/expanded-retrieval.json
python scripts/evaluate_helpfulness.py --extra-cases config/expanded-helpfulness-evaluation.json --extra-cases config/expanded-knowledge-evaluation.json --include-retrieval-cases --archive --output /tmp/expanded-replies.json
```

При доступной VM и настроенных ключах последний прогон можно выполнить с `--live flowise`. Он отправляет синтетические вопросы в Prediction API; только такой отдельный прогон и просмотр трасс/полных ответов подтвердят работу реальных Agentflows V2. После переноса корпуса бот должен быть перезапущен/пересобран. Веса и модель не менялись, а существующий протокол передачи источников Flowise сохранён.
