## Что изменилось

- Четыре формата: определение, ситуация, расчёт, документ. При недостатке данных для расчёта агент запрашивает график и параметры.
- Каждое содержательное предложение имеет C-ID. Модель выбирает S-ID источника и Q-ID готовой точной выдержки. Код подставляет цитату, проверяет полноту аудита, ссылки и числа, затем Python повторно проверяет результат.
- В каждом V2-графе 13 узлов: после первого аудита видна развилка, одна доработка и повторная проверка. Один успешный путь проходит 8 или 12 узлов, а не все 13. Неподтверждённый черновик не отправляется. Для обычного ответа допустимо сохранить самостоятельные подтверждённые части; для документа такое сокращение отключено.
- Добавлены [Правила расчёта ГЭСВ №44](https://old.adilet.zan.kz/rus/docs/V2600038333) и [приложение 1 к Требованиям №91](https://old.adilet.zan.kz/rus/docs/V2600038748). Поиск различает включаемые платежи, исключения и условность страховки. 104 материала: 30 PDF, 74 TXT; 28 176 фрагментов. Графические формулы в текст не извлечены, готовый численный калькулятор не заявлен.
- JSON Schema включён узким адаптером закреплённой Flowise 3.1.4 только для текущей модели. База, ключи и прежние графы сохранены.

## Где смотреть и как откатить

В Flowise → Agentflows → V2 откройте **STS Agentflow V2 — ЮрАгент — проверка утверждений** или **STS Agentflow V2 — ФинАгент — проверка утверждений**. Четыре прежних основных/тестовых маршрута уже используют новые графы; комнаты и история сохранены. Прежние пятиузловые графы оставлены для отката.

Закрытый план VM: `/app/handoff_state/claims-plan-20261022.json`. Для возврата прежних маршрутов:

```bash
docker exec sts-team-demo-bot-1 python /app/upgrade_agentflow_quality.py --state-dir /app/handoff_state --plan-file /app/handoff_state/claims-plan-20261022.json --rollback
docker restart sts-team-demo-bot-1
```

После этого при необходимости возвращается образ `sts-matrix-support-bot:before-claims-20261022` и исходные файлы из закрытого `before-app.tar.gz`. Для возврата адаптера Flowise сначала верните старые графы, затем пересоздайте только Flowise без третьего Compose-файла `claims-json-schema.yml`. Том PostgreSQL и ключи не удалять.
