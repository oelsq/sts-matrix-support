# Проверка доступа пользователей и департаментов — 11 ноября 2026

Проверена рабочая установка STS на VM, без изменения Qwen, инструкций, параметров генерации или моделей общего сервера.

## Реальные запросы через Matrix

В аккаунтах employee01–employee14 выполнены запросы через временные управляемые тестовые устройства с настоящим Olm/Megolm. Каждый ключ тестового устройства сопоставлялся с ключом, созданным самим скриптом, и опубликованным ключом конкретного устройства. Доверие не выдавалось всем устройствам аккаунта. До начала проверки у пользователей 1–14 не было активных опубликованных устройств и обработанных обращений.

| Проверка | Результат |
|---|---:|

| Ответы двух агентов на вопросы через настоящую модель | 28 из 28 |
| Ответы `!сотрудники` с пятью правильными адресатами | 28 из 28 |

ЮрАгент объяснял различие трудового договора и договора оказания услуг. ФинАгент объяснял различие вклада и кредита. Проверялись шифрование запроса и ответа, корреляция с запросом, получение содержательного ответа и отсутствие сообщения о недоступности генерации. Критерии содержания ограничены наличием основных терминов и объёмом ответа; это не экспертная юридическая или финансовая оценка.

Вопросы и ответы проверялись только для собственных синтетических запросов. Предыдущие пользовательские переписки не выгружались. На локальный компьютер переданы только итоговые показатели. Временная копия паролей в тестовом контейнере и криптографические хранилища тестовых клиентов удалены; основной защищённый файл выдачи аккаунтов сохранён.

## ЮрДеп и ФинДеп

В конфигурации остаются по пять сотрудников каждого департамента. Для каждого из пользователей 1–14 выполнены изолированные проверки выбора каждого из пяти сотрудников обоих направлений: 140 сочетаний. Проверялся правильный назначенный сотрудник, разделение пользователей и требование шифрования будущей комнаты. Это тест настоящего кода HumanHandoff с имитацией Matrix-создания комнаты, а не 140 реальных обращений сотрудникам.

Команды списка сотрудников проверены реальными зашифрованными запросами в 28 личных комнатах. Ответы живых сотрудников и фактическая передача им контекста этой серией не проверялись. У всех десяти сотрудников сейчас нет подтверждённых устройств со стороны бота. До их входа и проверки устройств передача зашифрованного контекста остаётся в ожидании.

## Что требуется при первом входе

Рабочие браузеры пользователей 1–14 не подтверждались автоматически. Каждый пользователь должен войти и сравнить ID сеанса и полный публичный Ed25519-отпечаток с оператором, как это сделано для employee15. Новая проверка устройства не меняет модель или её ответы.

Служебные сообщения проверки остались в личных чатах. Поскольку они были зашифрованы для одноразовых тестовых устройств, будущий браузер пользователя может не расшифровать эту тестовую историю. Это не проверка восстановления истории; для новых сообщений необходима проверка текущего устройства. Тестовый контекст сброшен командой `!новый`.

Идентичность бота, действующая конфигурация запуска и контрольные суммы 11 файлов логики Qwen, инструкций и поиска после проверки сохранились.
